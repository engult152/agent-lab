# agent-lab

基于 RAG 的本地知识库助手：把自己的文档变成可对话的资料库。**回答带出处，查不到就说不知道。**

## 功能

- 语义检索（按含义匹配，不是关键词）
- 多轮对话、工具调用（检索 / 列目录 / 读文件）
- 图片版 PDF：视觉模型逐页转录后入库
- 流式输出，首字 1 秒内出现
- 检索不到时明确拒答，不编造

## 快速开始

    uv sync
    # 新建 .env：DEEPSEEK_API_KEY=sk-xxx  SILICONFLOW_API_KEY=sk-xxx
    # 文档放进 docs/
    uv run streamlit run app.py

## 评估

38 条测试集（30 正例 + 8 负例）

| 指标 | 结果 |
|---|---|
| 检索召回 | 28/30 = 93% |
| 端到端准确率 | 36/38 = 95% |
| 稳定性（重复 3 次） | 18/18 |
| 单问响应 | 1.9 ~ 3.5 秒 |

## 设计决策

- 手写 function calling 循环，不用框架：为了看清模型怎么决策、工具结果怎么回填
- 阈值 0.58：在测试集上从 0.45 扫到 0.65 得出，没有通用值
- 切块保留章节标题：否则问「第六章」时章节信息已丢失
- 视觉模型代替 OCR：OCR 不懂版面，图注表格会乱

## 已知局限

- 几千段以内可用，再多需要向量数据库
- 一句话问两件事的复合问题召回率下降
- 只支持 md / txt / PDF
- 单用户，无权限控制
