# AI 开发环境踩坑记录

## Git 安装后默认编辑器是 Vim
现象：执行不带 -m 的 git commit 会进入全屏界面，按什么都没反应，像是卡死。
解决：按 Esc，然后输入 :wq 回车（保存退出），或 :q! 回车（不保存退出）。
预防：安装时把默认编辑器改成 VS Code；或执行 git config --global core.editor "code --wait"。

## winget 下载极慢
现象：winget install 卡在下载，速度只有几十 KB/s。
原因：winget 的安装包直接从 github.com 下载，国内直连很慢，而且 winget 不支持换源。
解决：看它输出的 URL，指向 github.com 的改用国内镜像手动下载。Git 用 npmmirror 的 git-for-windows 镜像，Python 用华为云或 npmmirror 的 python 镜像。

## PowerShell 禁止运行脚本
现象：执行 npm 时报错「无法加载文件 npm.ps1，因为在此系统上禁止运行脚本」。
原因：Windows 默认执行策略是 Restricted，只允许运行签名脚本。
解决：Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned，然后重开终端。

## Python 安装后 python 命令找不到
现象：输入 python 没反应，where python 输出为空，或打开微软商店。
原因：安装时没有勾选 Add python.exe to PATH（这个选项默认不勾）。
解决：把 Python312 和 Python312\Scripts 两个目录加入用户环境变量 Path，然后必须重开终端。
注意：修改环境变量后不重开终端，当前窗口读到的仍是旧值。

## Python 版本怎么选
现象：3.12.16 目录里只有 tar.xz 源码，没有 exe 安装包。
原因：Python 3.12 从 3.12.11 起进入仅安全修复阶段，官方不再制作 Windows 安装包。
解决：安装 3.12.10，这是 3.12 系列最后一个带 Windows 安装包的版本。

## uv 项目里没有 main.py
现象：uv run python main.py 报 can not open file。
原因：uv init 生成了 src 布局，代码应放在 src 项目名 目录下，根目录没有 main.py。
解决：直接在根目录新建 main.py 写代码，或使用 src 布局对应的入口。

## 401 Authentication Fails
现象：调用模型报 401，提示 api key invalid。
排查顺序：先确认 .env 里 key 长度是否正确（DeepSeek 是 35 位，硅基流动是 51 位），再检查有没有多余空格或引号，最后确认这个 key 是否已被删除。
注意：看到 401 先查 key，不要改代码，代码通常是好的。

## 编辑 main.py 后行为没变化
现象：改完代码重新运行，输出和以前一模一样。
原因：新代码粘贴在文件末尾，旧函数还在，REGISTRY 仍然指向旧实现。
解决：用 Select-String -Path main.py -Pattern "^def |^REGISTRY" 检查函数和注册表，确认没有重复定义。

## 向量检索的分数怎么看
现象：所有段落的相似度分数都挤在 0.4 到 0.6 之间，设 0.35 的阈值等于没有过滤。
原因：embedding 的绝对分数和模型、语言、文本长度都有关，没有通用阈值。
解决：看相对排序而不是绝对分数；阈值按自己的数据分布调；更稳的做法是把分数一起交给模型判断。

## 问中文问题时要先启动程序
现象：把中文问题直接敲进 PowerShell，报「无法将 XXX 项识别为 cmdlet」。
原因：PowerShell 只认命令，不认自然语言。
解决：先运行程序，看到「你:」提示符后再输入问题。判断依据是提示符是 PS 还是 你:。
